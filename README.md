TP WinForm — Gestión de artículos

Aplicación de escritorio desarrollada en C# con Windows Forms para la gestión de artículos de un catálogo comercial.

El sistema está diseñado para ser genérico, permitiendo administrar información que posteriormente podría ser consumida por distintos servicios, como sitios web, e-commerce o aplicaciones móviles.

Funcionalidades

- Listado de artículos.
- Búsqueda por distintos criterios.
- Alta de artículos.
- Modificación de artículos.
- Eliminación de artículos.
- Visualización del detalle de un artículo.
- Administración de marcas y categorías.
- Gestión de una o múltiples imágenes por artículo.
- Persistencia de la información en una base de datos.

Datos de los artículos

Cada artículo contempla, como mínimo:

- Código
- Nombre
- Descripción
- Marca
- Categoría
- Imagen/es
- Precio

Desarrollo

El proyecto se plantea en dos etapas:

Etapa 1: desarrollo de las clases del modelo, las ventanas de la aplicación y su navegación.

Etapa 2: integración con la base de datos y desarrollo de las validaciones y funcionalidades correspondientes.
